# Coralogix AWS Lambda Telemetry Exporter

Coralogix AWS Lambda Telemetry Exporter collects telemetry from AWS Lambda functions and ships it to Coralogix.

See the [documentation](https://coralogix.com/docs/coralogix-aws-lambda-telemetry-exporter/).

Coralogix AWS Lambda Telemetry Exporter underpins the [OpenTelemetry Lambda Auto Instrumentation](https://coralogix.com/docs/otel-lambda-auto-instrumentation/)
